# devlog-kr

유튜브 개발 일지 채널 **[버그로그](https://www.youtube.com/@buglog_kr)**에서 만드는 프로그램을 모아 두는 저장소입니다. 프로그램마다 폴더 하나를 씁니다.

만드는 과정과 그 과정에서 나온 버그를 찾고 고치는 이야기를 영상으로 올립니다.

| 프로젝트 | 설명 | 상태 |
|---|---|---|
| [cpu-bench](cpu-bench/) | 점수만 보여 주지 않고, 내 PC가 제 성능을 내는지와 그 이유까지 알려 주는 Windows용 진단형 CPU 벤치마크 · [내려받기](https://github.com/song-circle/devlog-kr/releases?q=cpu-bench) | 개발 중 (0.5.0 배포) |
| [코드반장](codebanjang/) | 요청을 AI 팀(PM·개발·QA)이 나눠 실제로 코드를 고치고 테스트로 검증한 뒤, 내가 승인해야만 반영되는 Windows 앱. 비용·실패 횟수를 전부 기록 | 개발 중 |

상태 표시: **개발 중** / **운영 중** / **유지보수만** (버그 수정만) / **보관** (더 이상 고치지 않음)

## 다음에 만들 프로그램 추천

"이런 프로그램 있었으면 좋겠다" 싶은 게 있으면 [유튜브](https://www.youtube.com/@buglog_kr) 아무 영상에 댓글로 남기거나, 자세히 적고 싶으면 [Issues](../../issues)에 `[요청]`을 제목 앞에 붙여 남겨 주세요. 검토해서 고른 프로그램은 개발 과정을 영상으로 올리고 무료로 배포합니다.

고르는 기준: Windows 프로그램 위주, 몇 주 안에 쓸 수 있는 첫 버전이 나올 것, 많은 사람에게 쓸모 있을 것.

만들지 않는 것: 게임 약관을 어기는 매크로·핵, 다른 서비스 약관을 어기는 자동화·수집, 남의 개인정보를 모으는 프로그램, 불법 복제·인증 우회.

|---|---|---|
