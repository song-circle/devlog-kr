# ledger 명세

CSV 거래 기록을 읽어 계좌별 잔액과 월별 요약을 만든다. 금액은 부동소수점을 쓰지 않고 **정수 센트(int64)** 로 다룬다.

## 입력 형식
- 첫 줄은 헤더 `date,account,amount,memo`. 대소문자는 구분하지 않고 각 칸의 앞뒤 공백은 무시한다. 헤더가 다르거나 없으면 거래 없이 `RowError{Line: 1, Msg: "bad header"}` 하나만 돌려준다.
- CSV 규칙은 표준(RFC 4180, Go `encoding/csv`)을 따른다: 따옴표로 감싼 칸은 쉼표, 따옴표(`""`), 줄바꿈을 포함할 수 있다.
- 완전히 빈 줄은 무시한다.
- 칸 수가 4개가 아닌 줄은 오류다.

## 칸 규칙 (앞뒤 공백은 모두 먼저 제거)
- `date`: `YYYY-MM-DD`, 실제로 있는 날짜(윤년 포함). 아니면 오류.
- `account`: 비어 있으면 오류.
- `amount`: 선택적 `-` 하나, 숫자 1개 이상, 선택적으로 `.` 뒤에 숫자 1~2개. `+`, 천 단위 쉼표, 지수 표기, `.5`, `5.`, `1.234`는 모두 오류. `"-0"`, `"-0.00"`은 0이다.
- `memo`: 그대로(빈 칸 가능, 앞뒤 공백 제거).

## 오류 처리
- 오류가 있는 줄은 `RowError{Line, Msg}`로 모으고 **나머지 줄은 계속 읽는다**. `Msg`는 어떤 칸이 왜 틀렸는지 알 수 있으면 자유 형식.
- `Line`은 그 기록이 **시작하는 파일의 실제 줄 번호(1부터)** 다. 앞 기록의 메모에 줄바꿈이 들어 있으면 그만큼 뒤로 밀린다.
- 오류도 거래도 파일에 나온 순서대로 돌려준다.

## API (`ledger.go`에 선언되어 있음)
- `Parse(r io.Reader) ([]Txn, []RowError)`
- `Balances(txns []Txn) map[string]int64` — 계좌별 센트 합계
- `Monthly(txns []Txn) []MonthSummary` — `Month`(`"YYYY-MM"`) 오름차순. `In`은 양수 금액 합, `Out`은 음수 금액 합(음수로), `Net = In + Out`. 거래가 없는 달은 넣지 않는다.
- `FormatCents(c int64) string` — 천 단위 쉼표, 소수 둘째 자리까지 항상 표시. 예: `123450` → `"1,234.50"`, `-5` → `"-0.05"`, `0` → `"0.00"`, `-100000000` → `"-1,000,000.00"`.
